# Magic-Wand-Triki-kapsel-
Triki Wand: silnik sterowania kursoremCelAplikacja webowa i silnik, który zamienia ruch kontrolera Triki (Żabka) w precyzyjne sterowanie kursorem. Kursor ma reagować na kierunek wskazywania kapslem (tryb różdżki), a nie na samo obracanie go wokół osi, jak w obecnej myszce. Wykorzystujemy wszystkie dostępne dane: żyroskop, akcelerometr i przycisk.
